stackvm playground

Tiny stack-based bytecode VM — value stack, call frames, and a handful of opcodes. Paste a flat opcode list (comma / space separated numbers) or pick a demo. Built by Sumit Kumar Ta (SK090347).

Opcodes: CONST=0 ADD=1 SUB=2 MUL=3 DIV=4 NEG=5 PRINT=14 HALT=15 POP=16 · format: 0 3 0 4 1 15 → CONST 3, CONST 4, ADD, HALT
